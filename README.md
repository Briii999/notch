# 📘 Project README

---

## 📌 Deskripsi

Project ini berisi file **TypeScript (`.ts`)** yang dapat dijalankan langsung menggunakan **ts-node** tanpa perlu proses build atau compile terlebih dahulu.

---

## 🧰 Prasyarat

Pastikan environment kamu sudah memiliki:

- **Node.js** (versi LTS disarankan)
- **npm** atau **yarn**
- **ts-node**
- **TypeScript**

---

## 📦 Install ts-node & TypeScript

Jika `ts-node` dan `typescript` belum terinstall, jalankan salah satu perintah berikut:

### Install global

```bash
npm install -g ts-node typescript
```
